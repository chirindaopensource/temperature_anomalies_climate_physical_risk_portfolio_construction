## Key callables, Tasks 1 to 40

Below is an abbreviated discussion of the Inputs, Processes and Outputs (IPOs) of the key callables in the "*Temperature Anomalies and Climate Physical Risk in Portfolio Construction*" research pipeline:


### Task 1 — `orchestrate_task_1`

- **Inputs**: `t_observed_seconds: Optional[float] = None`, `manifest_path: str | Path`, `seed_log_path: str | Path`, `run_manifest_path: str | Path`, `config: Optional[Dict[str, Any]] = None`, keyword-only `output_dir: Optional[Path] = None`.
- **Process**: validates the 21-key `STUDY_CONFIG` (`build_default_study_config`, `validate_study_config`, `scan_unspecified_fields`) and the seed protocol (seeds exactly $\lbrace 1, \dots, 10 \rbrace$, estimator seed 42, PCG64) before any write; builds the pristine generator registry; builds and atomically writes the environment manifest and seed-state log.
- **Outputs**: `Dict[str, Any]` with `manifest`, `hardware_ratio`, `seeds`, `estimator_seed`, `config`, `config_checksum`, `validation_report`, `unspecified_fields`, `seed_registry`, the log paths and `library_checklist`.
- **Transformation**: configuration and seed integers become a validated, checksummed configuration plus one PCG64 generator state per MOPSO run, persisted before any random draw.
- **Research role**: reproducibility scaffolding for the stochastic optimiser; the manuscript averages "10 independent runs of the optimization process" and reports that "the time execution is 217.39 seconds per month".
- **Equations**: none from the manuscript. The code defines a hardware ratio $h = 217.39 / T_{observed}$; this is a code construct, not an equation of the paper.
- **Code/paper note**: when `t_observed_seconds` is None, `hardware_ratio` is recorded as null with status `pending_anchor_measurement` rather than a fabricated value; the manuscript specifies no such ratio.
- **Scope**: Table C.10 hyperparameters ($N_{pop} = 500$, $\operatorname{Iter} = 300$, $N_{rep} = 400$, $N_{grid} = 10$, $\alpha = 0.1$, $\beta = \gamma = 1$, $\mu = 2$, $\omega = 0.8$, $c_1 = c_2 = 1.5$) are pinned inside the default configuration.

### Task 2 — `orchestrate_task_2`

- **Inputs**: `df_temperature: pd.DataFrame`, `df_returns: pd.DataFrame`, `df_market: pd.DataFrame`, `df_riskfree: pd.DataFrame`, `aux_tables: Dict[str, pd.DataFrame]` (eight auxiliary tables), `log_dir: Optional[Path] = None`, keyword-only `allow_fatal: bool = True`.
- **Process**: runs three validators in fixed order: `validate_temperature_panel` (six invariants), `validate_firm_returns_panels` (keys, 2004-01 to 2025-04 coverage, positive market cap, return band, currency codes) and `validate_fundamentals_panels` (primary keys, membership snapshots 2020-01-01 and 2025-01-01, trading calendar, segment tables); each writes a JSON-lines audit log.
- **Outputs**: `Dict[str, Any]` with the indexed panels, the three validation reports and `overall_passed`.
- **Transformation**: raw heterogeneous tables become typed, MultiIndexed panels plus structured INFO/WARNING/FATAL records; data values are not modified.
- **Research role**: data-provenance gate for the inputs described in Section 2, where the study uses "monthly mean temperature data for the period spanning from January 1, 1940, to April 30, 2025" and return data over 2004 to 2025.
- **Equations**: none; this stage precedes Equation (1).
- **Code/paper note**: with `allow_fatal=True` (default) FATAL records are aggregated, not raised; `allow_fatal=False` raises after all three stages have logged. A `RuntimeError` is raised if the overall verdict disagrees with the stage verdicts.
- **Scope**: validation only; cleansing is deferred to Task 3.

### Task 3 — `orchestrate_task_3`

- **Inputs**: `df_temperature`, `df_returns`, `universe`, `metadata`, `fundamentals`, `segment_revenue`, `fx_rates` (all `pd.DataFrame`), `log_dir: Optional[Path] = None`, `reviewed_outlier_keys: Optional[set] = None`, keyword-only `allow_fatal: bool = False`.
- **Process**: `cleanse_temperature_panel` drops missing or non-canonical rows with reason codes and re-checks baseline cell counts; `cleanse_firm_returns_panel` drops non-positive caps, winsorises `total_return_usd` at the full-sample 1st and 99th percentiles, and deduplicates revisions; `reconcile_cross_tables` enforces foreign-key, FX and revenue closures.
- **Outputs**: `Dict[str, Any]` with `temperature_clean`, `returns_clean`, `reconciliation`, `closure_records`, `ledgers`, `overall_passed` (plus `fatal_closures` when `allow_fatal=True`).
- **Transformation**: validated panels become cleansed panels whose row ledgers satisfy rows in minus rows dropped equals rows retained, verified numerically.
- **Research role**: implements the data-engineering requirement of "Robust handling of gaps or outliers in temperature and return series" for the total-return series the paper uses ("We utilize total returns").
- **Equations**: none.
- **Code/paper note**: the 1st/99th percentile winsorisation and the FX closure rules are code-level policies; the manuscript does not describe winsorisation.
- **Failure mode**: by default any FATAL cross-table closure (for example a missing FX rate) raises `ValueError` after artifacts are confirmed on disk.

### Task 4 — `orchestrate_task_4`

- **Inputs**: `df_clean: pd.DataFrame` (cleansed temperature panel), `out_dir: Optional[Path] = None`, `log_dir: Optional[Path] = None`.
- **Process**: `filter_baseline_window` keeps 1960-01 to 1990-12; `compute_baseline_moments` aggregates $\mu_{k,m}$ and $\sigma_{k,m}$ per continent and calendar month; `validate_baseline_moments` checks positivity, finiteness and the exact $6 \times 12$ key set; `save_baseline_moments` persists with an explicit schema; a replay proof checks 72 cells in the persisted log.
- **Outputs**: `Dict[str, Any]` with `baseline`, `moments` (72 rows: `mu`, `sigma`, `sigma_ddof0`, `n`), `validation`, artifact paths and `overall_passed`.
- **Transformation**: a monthly temperature series per continent becomes 72 seasonal reference moments.
- **Research role**: supplies the moments of Equation (1); the paper states "we establish a reference period (baseline) spanning from 1960 to 1990" and computes moments "using only the observations within this 30-year window".
- **Equations**: the moments are the $\mu_{k,m}$ and $\sigma_{k,m}$ of Equation (1), shown under Task 5.
- **Code/paper note**: inclusive endpoints give 31 years (31 observations per cell), not 30; this is recorded as judgment call JC-baseline. `sigma` uses the sample divisor (ddof = 1); the ddof = 0 value is kept as a diagnostic because the manuscript does not specify the divisor.
- **Failure mode**: any NaN inside the baseline window or any cell count other than 31 is FATAL.

### Task 5 — `orchestrate_task_5`

- **Inputs**: `df_clean: pd.DataFrame`, `moments: pd.DataFrame` (the 72-row Task 4 output), `out_dir: Optional[Path] = None`.
- **Process**: `join_baseline_moments` joins many-to-one on (continent, calendar month) with a month-drift guard; `compute_standardized_anomaly` evaluates Z in vectorised form; `validate_anomaly_panel` checks for NaNs, the 72 diagnostic cells and baseline-window moments of Z; `save_anomaly_panel` persists with a checksum.
- **Outputs**: `Dict[str, Any]` with `joined`, `panel` (Z indexed by continent and `year_month`), `diagnostics`, paths and `overall_passed` (validation, artifacts on disk, unchanged row count).
- **Transformation**: raw temperature $T_{k,t}$ becomes a unit-free standardised anomaly that is comparable across continents and months.
- **Research role**: implements Equation (1): the raw temperature "is transformed into a standardized anomaly".

$$
Z_{k,t} = \frac{T_{k,t} - \mu_{k,m}}{\sigma_{k,m}}
$$

- **Code/paper note**: faithful to Equation (1), with $m$ the calendar month of $t$ and $\sigma_{k,m}$ the ddof = 1 baseline deviation from Task 4.

### Task 6 — `orchestrate_task_6`

- **Inputs**: `panel: pd.DataFrame` (anomaly panel with Z), `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None` (threshold and operator source).
- **Process**: `build_bernoulli_indicator` applies a strict comparison, with a boundary self-check at the threshold and its adjacent floats; `compute_prevalence_windows` computes prevalence over the full, restricted and averaging windows against the Gaussian reference; `persist_bernoulli_panel` writes the panel, the prevalence table and a configuration snapshot after a row-count proof.
- **Outputs**: `Dict[str, Any]` with the int8 Bernoulli panel (MultiIndex continent and `year_month`), the 18-row prevalence frame and paths.
- **Transformation**: a continuous anomaly becomes a binary extreme-event indicator.
- **Research role**: implements Equation (2): "An extreme event is recorded when the standardized temperature exceeds a critical threshold of 2".

$$
B_{k,t} = 1 \ \text{if } Z_{k,t} > 2, \qquad B_{k,t} = 0 \ \text{otherwise}
$$

- **Code/paper note**: faithful, including strict inequality; the prevalence comparison uses the 2.28% Gaussian upper-tail reference stated in the text.

### Task 7 — `orchestrate_task_7`

- **Inputs**: `bernoulli: pd.DataFrame` (continent, `year_month`, B), `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `fit_all_continents` fits one logit per continent by Newton iterations over 1940-01 to 2025-04 in an orthogonalised time basis, then back-transforms to monomial $\beta_0, \beta_1, \beta_2$; `predict_probability_panel` projects the fitted probabilities onto the shared monthly grid with a stable sigmoid; `persist_logit_artifacts` writes coefficients, probabilities and the time-origin metadata.
- **Outputs**: `Dict[str, Any]` with the six-row coefficient table (with standard errors and diagnostics), the $6 \times T$ probability panel `p_hat`, and paths.
- **Transformation**: binary event histories become smooth, time-varying event probabilities $\hat{p}_{k,t}$.
- **Research role**: implements Equation (3); "the model incorporates a quadratic time trend" to capture accelerating risk.

$$
\operatorname{logit}(p_{k,t}) = \ln\left( \frac{p_{k,t}}{1 - p_{k,t}} \right) = \beta_{0,k} + \beta_{1,k}t + \beta_{2,k}t^2
$$

- **Code/paper note**: the orthogonal basis is an exact reparameterisation, so the fitted probabilities are those of Equation (3). The time index ($t$ = months since 1940-01 plus one) is a code convention; the manuscript does not define it. Non-convergence is FATAL.

### Task 8 — `orchestrate_task_8`

- **Inputs**: `bernoulli: pd.DataFrame`, `probability: pd.DataFrame` (continent, `year_month`, `p_hat`), `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `compute_auroc_per_continent` computes the Mann-Whitney AUROC (ties count one half) with a seeded moving-block bootstrap interval and compares it to Table 1 within 0.02; `compute_aupr_per_continent` computes step-interpolated AUPR and the prevalence baseline; `build_table1_and_figure1` writes Table 1, a deviation log and Figure 1 (1940 to 2020).
- **Outputs**: `Dict[str, Any]` with the AUROC and AUPR tables, Table 1, paths and `overall_passed` (AUROC within tolerance, AUPR above baseline, artifacts present).
- **Transformation**: pairs $(B_{k,t}, \hat{p}_{k,t})$ become per-continent discrimination scores.
- **Research role**: reproduces Table 1: "all continents exhibit exceptionally high AUROC values, ranging from 0.8380 for Europe to 0.9396 for Africa", with the AUPR random baseline taken as "the positive-class prevalence".
- **Equations**: none numbered; the metrics are standard.
- **Code/paper note**: the block-bootstrap intervals are an addition; the manuscript reports point values only. AUPR is computed by step interpolation (average precision); the manuscript does not state its interpolation rule.
- **Scope**: the evaluation uses the full-sample fit (1940 to 2025), consistent with the text's training period for Table 1.

### Task 9 — `orchestrate_task_9`

- **Inputs**: `bernoulli: pd.DataFrame`, `restricted_end: Optional[str] = None` (default 2019-12-31), `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `resolve_restricted_end` resolves the end date once; `fit_full_and_restricted` fits Equation (3) on 1940-01 to 2025-04 and on 1940-01 to the restricted end, reusing Task 7's stabilised fitter, and projects both onto the full grid; `compute_overlap_divergences` computes the maximum and RMS divergence over the overlap; `validate_return_schema` checks the three-key schema.
- **Outputs**: `Dict[str, Any]` with keys `full_fit`, `restricted_fit` and `comparison_metrics`, each keyed by continent; an optional sidecar JSON with the grid and curves.
- **Transformation**: one Bernoulli panel becomes two coefficient sets and two probability curves per continent, plus divergence scalars $\max_t \lvert p_{full}(t) - p_{rest}(t) \rvert$ and the RMS equivalent.
- **Research role**: out-of-sample stability check; "The fitted curve from the restricted training set closely tracks the curve estimated on the full sample."
- **Equations**: Equation (3), applied on two windows (see Task 7).
- **Code/paper note**: the divergence metrics are code-level quantifications of a visual claim; the manuscript gives no numerical criterion. The text names the restricted sample 1940-2019, matching the default end date.
- **Scope**: `out_dir=None` performs no filesystem writes.

### Task 10 — `orchestrate_task_10`

- **Inputs**: `bernoulli: pd.DataFrame`, `restricted_end: Optional[str] = None`, `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `invoke_and_validate_orchestrator` calls `orchestrate_task_9`, checks coverage and writes a run-versioned JSON snapshot with a SHA-256; `summarize_divergences` audits each continent against a 0.05 maximum-deviation threshold (WARNING only) and persists the per-month divergence series; `render_figure2` draws the full versus restricted curves for Europe and North America.
- **Outputs**: `Dict[str, Any]` with the Task 9 triple, the divergence summary and figure paths.
- **Transformation**: the two-window fit becomes an audited divergence table and Figure 2.
- **Research role**: delivers Figure 2, "comparing forecasts derived from logistic regressions estimated over two distinct sample periods".
- **Equations**: none beyond Equation (3), inherited from Task 9.
- **Code/paper note**: the 0.05 threshold is a documented judgment call (JC-divergence-warn-threshold) and is not stated in the manuscript. It never aborts the run.
- **Scope**: the restricted end is read back from Task 9's result rather than re-resolved, which prevents two resolution paths from drifting.

### Task 11 — `orchestrate_task_11`

- **Inputs**: `bernoulli: pd.DataFrame`, `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `pivot_bernoulli_wide` reshapes to a 972-month by 6-continent frame over 1940-01 to 2020-12 without listwise deletion; `persist_pivot` writes it; `compute_empirical_correlation` computes the pairwise-complete $6 \times 6$ Pearson (phi) matrix with symmetry and unit-diagonal proofs; `render_correlation_heatmap` draws Figure 3 on a fixed $[0, 0.5]$ colour range.
- **Outputs**: `Dict[str, Any]` with the wide pivot, the correlation matrix and figure paths.
- **Transformation**: six binary series become the empirical dependence matrix $\hat{\rho}_{k,j}$ used by Tasks 13, 24, 27 and 31.
- **Research role**: Section 2.2: "all estimated Pearson coefficients are positive", "with values ranging between 0 and 0.48".
- **Equations**: none numbered; Pearson correlation of $B_{i,t}$ and $B_{j,t}$.
- **Code/paper note**: the 1940 to 2020 estimation window is a code choice aligned with the averaging window of Task 12; the manuscript does not state the window for Figure 3.
- **Scope**: negative cells, if any, clip visually at the bottom of the fixed colour range but are annotated with their signed values.

### Task 12 — `orchestrate_task_12`

- **Inputs**: `probability: pd.DataFrame` (full `p_hat` panel), `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None` (averaging-window label).
- **Process**: `filter_averaging_window` keeps 1940-01 to 2020-12 (972 months, 5,832 rows); `compute_time_averaged_marginals` takes the equal-weighted mean per continent; `validate_marginals` enforces six continents and $0 < \bar{p}_k < 1$, flagging values near the boundary.
- **Outputs**: `Dict[str, Any]` with the filtered panel, the six-row marginals frame (`p_bar`, `n_obs`, `near_boundary`) and paths.
- **Transformation**: a time-varying probability panel becomes one representative marginal per continent.
- **Research role**: resolves the non-stationarity of the bounds; the authors "decide to use the mean value of the estimated parameters" over 1940 to 2020.

$$
\bar{p}_k = \frac{1}{T}\sum_{t=1}^T \hat{p}_{k,t}
$$

- **Code/paper note**: faithful, with $T = 972$. The formula carries no printed number in the paper, so none is cited. A configured window label other than 1940-2020 is FATAL rather than silently ignored.

### Task 13 — `orchestrate_task_13`

- **Inputs**: `marginals: pd.DataFrame` (continent, `p_bar`), `empirical: pd.DataFrame` ($6 \times 6$ Pearson matrix), `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `compute_rho_min_matrix` and `compute_rho_max_matrix` evaluate the closed forms with vectorised outer operations and verify the corollary's extremal cases on fixtures; `verify_admissibility_and_plot` checks $\rho_{\min} \le \hat{\rho} \le \rho_{\max}$ for all 15 pairs (tolerance 1e-6, FATAL on breach) and draws Figure 4.
- **Outputs**: `Dict[str, Any]` with both bound matrices, the denominator-instability `flags`, the admissibility audit and figure paths.
- **Transformation**: marginals become pairwise admissible correlation intervals, against which the empirical matrix is tested.
- **Research role**: Equations (5) and (6); "This visualization confirms that the empirical estimates fall strictly within the feasible theoretical range."

$$
\rho_{\min} = \frac{\max(0, p_1 + p_2 - 1) - p_1 p_2}{\sqrt{p_1(1 - p_1)}\sqrt{p_2(1 - p_2)}}
$$

$$
\rho_{\max} = \frac{\min(p_1, p_2) - p_1 p_2}{\sqrt{p_1(1 - p_1)}\sqrt{p_2(1 - p_2)}}
$$

- **Code/paper note**: faithful to (5) and (6), with $p_1, p_2$ set to $\bar{p}_k$. Strict interiority is logged but not FATAL; the caption states that pairwise bounds are necessary but not sufficient for six variables (Huber and Marić).

### Task 14 — `orchestrate_task_14`

- **Inputs**: `df_membership: pd.DataFrame`, `df_returns: pd.DataFrame`, `df_metadata: pd.DataFrame`, `out_path: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None` (anchors, grid dates, path overrides).
- **Process**: `filter_dual_constituent_candidates` keeps MSCI World members at 2020-01-01 and 2025-01-01 and excludes firms with two or more consecutive missing returns over 2004-01 to 2025-04; `select_stratified_universe` ranks firms by the last market cap strictly before the anchor within each headquarters region and fills the Table 4 quotas; `persist_frozen_universe` writes the 120 firms, the sorted canonical order and its SHA-256.
- **Outputs**: `Dict[str, Any]` with the candidate list, the 120-row universe, paths and a precedence report.
- **Transformation**: a membership history becomes a frozen, ordered 120-firm investment universe (54 North America, 30 Europe, 30 Asia, 6 Oceania).
- **Research role**: survivorship control ("constituents of the MSCI World index at the beginning of 2020 and 2025") and Table 4, where "the selection follows a stratified sampling approach based on market capitalization and location of the headquarter".
- **Equations**: none.
- **Code/paper note**: the gap rule and the top-market-cap-within-region rule are code interpretations; the manuscript gives no gap rule and does not state the within-region selection rule beyond market capitalisation.
- **Scope**: the frozen order is the alignment key for Tasks 16, 22 and 31.

### Task 15 — `orchestrate_task_15`

- **Inputs**: `df_fundamentals: pd.DataFrame`, `universe_ids: List[str]` (frozen 120 firms), `df_metadata: pd.DataFrame`, `out_path: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `select_point_in_time_fundamentals` selects one eligible row per firm with effective date before 2020-01-01, handling restatements strictly; `compute_asset_intensity` divides tangible assets by revenue with positivity guards; `validate_sector_intensity_benchmarks` compares sector means with the text's values (Real Estate 10.6, Retailers 0.6).
- **Outputs**: `Dict[str, Any]` with the selected rows, the AI frame indexed by `firm_id`, the benchmark report and paths.
- **Transformation**: balance-sheet and income-statement levels become a dimensionless physical-vulnerability ratio per firm.
- **Research role**: Equation (11); the ratio "reflects the degree of a company's dependency on physical assets to generate revenue".

$$
AI_i = \frac{\text{Tangible Assets}_i}{\text{Revenue}_i}
$$

- **Code/paper note**: faithful to (11). The point-in-time cut-off at the 2020-01-01 anchor is a look-ahead control; the manuscript does not state the fundamentals date.

### Task 16 — `orchestrate_task_16`

- **Inputs**: `df_segment_revenue: pd.DataFrame`, `df_map: pd.DataFrame` (segment-to-continent map), `df_fundamentals: pd.DataFrame` (one row per firm), `out_path: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`, keyword-only `audit_path`, `frozen_order`, `frozen_universe_path`, `expected_order_hash`.
- **Process**: `normalize_and_explode_mapping` normalises labels, explodes multi-continent labels and requires allocation weights to sum to one per label; `aggregate_mapped_continent_revenue` sums segment revenue times allocation weight per firm-year-continent with revenue conservation; `compute_revenue_shares` records the residual against total revenue and normalises to shares.
- **Outputs**: `Dict[str, Any]` with the normalised and mapped frames, long-form and wide-form $S_{i,k}$ (reindexed to the frozen order) and paths.
- **Transformation**: disclosed geographic segment revenues become continental revenue shares with $\sum_k S_{i,k} = 1$ per firm.
- **Research role**: supplies $S_{i,k}$, "the revenue produced in continent" $k$ by firm $i$, normalised "so that each firm's shares sum to one", for Equation (12).
- **Equations**: $S_{i,k}$ enters Equation (12), shown under Task 22.
- **Code/paper note**: the proportional residual distribution is inert for the shares, because it rescales every mapped revenue by the same factor; it is kept only for audit. The manuscript defines $S_{i,k}$ as revenue but uses it as a share; the code implements the normalised share.
- **Failure mode**: a firm in the frozen order that is missing from the output is FATAL.

### Task 17 — `orchestrate_task_17`

- **Inputs**: `df_returns: pd.DataFrame`, `df_metadata: pd.DataFrame`, `df_mkt: pd.DataFrame`, `df_rf: pd.DataFrame`, `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None` (financial-exclusion list).
- **Process**: `aggregate_sector_returns` forms same-month cap-weighted sector returns $R_{s,t}$, with weights renormalised after exclusions and financial sectors removed; `explode_sector_continent_panel` replicates each sector-month row across the six continents; `construct_excess_returns` converts the risk-free rate to a monthly holding-period basis and subtracts it from sector and market returns.
- **Outputs**: `Dict[str, Any]` with the sector, exploded and excess-return frames, the risk-free conversion audit and paths.
- **Transformation**: firm total returns become the dependent variable $R_{s,k,t} - R_{f,t}$ and the regressor $R_{MKT,t} - R_{f,t}$ of Equations (8) to (10).
- **Research role**: the sector return is "calculated as the market capitalization weighted average of the individual total returns of its constituent firms", and "we exclude sectors regarding banks, financial and insurance companies".
- **Equations**: supplies the left-hand side and market term of Equation (8), shown under Task 18.
- **Code/paper note**: $R_{s,k,t}$ is identical across $k$ by construction (intentional replication), so the continent index enters only through $B_{k,t}$. Same-month cap weights carry a mild look-ahead, which is documented (JC-sector-return-weight-timing); the manuscript does not specify weight timing.
- **Scope**: the row-count invariant is the number of sector rows times six, which admits unbalanced sector panels.

### Task 18 — `orchestrate_task_18`

- **Inputs**: `df_sector_excess: pd.DataFrame`, `df_mkt_excess: pd.DataFrame`, `df_bernoulli: pd.DataFrame`, `out_path: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`.
- **Process**: `estimate_sector_continent_ols` fits one OLS per (sector, continent) cell over 2004-01 to 2025-04 and logs the factor-indicator VIF; `compute_hac_gamma_table` derives Newey-West HAC errors (Bartlett kernel) from the same fit, with lag $L = \lfloor 4(T/100)^{2/9} \rfloor$ and Student-t p-values on $T - 3$ degrees of freedom; `build_table_2` keeps $p < 0.10$, adds stars and compares with the manuscript's reference cells.
- **Outputs**: `Dict[str, Any]` with the fits, the full gamma table, Table 2 and paths.
- **Transformation**: excess-return and event panels become cell-level climate sensitivities $\gamma_{s,k}$ with robust inference.
- **Research role**: Equation (8), estimated with "HAC (Heteroskedasticity and Autocorrelation Consistent) robust standard errors"; the text reports that "17 out of 23 sectors exhibit returns that are significantly impacted".

$$
R_{s,k,t} - R_{f,t} = \alpha_{s,k} + \beta_{MKT,s,k}(R_{MKT,t} - R_{f,t}) + \gamma_{s,k}B_{k,t} + \epsilon_{s,k,t}
$$

- **Code/paper note**: faithful to (8). The lag rule $\lfloor 4(T/100)^{2/9} \rfloor$ is the one recorded in the study configuration (`HAC_lag_rule` in config.yaml); the manuscript body does not state it. The small-sample correction is off, and the Student-t versus normal convention is a code choice.

### Task 19 — `orchestrate_task_19`

- **Inputs**: `df_sector_excess`, `df_mkt_excess`, `df_bernoulli` (all `pd.DataFrame`), `pooling_scope: str = 'sector_level'` (or `'global'`), `out_dir: Optional[Path] = None`, `config: Optional[Dict[str, Any]] = None`, keyword-only `allow_single_scope: bool = False`, `run_id: Optional[str] = None`.
- **Process**: `validate_panel_fe_scope`; `build_panel_fe_long_panel` (window 2004-01 to 2025-04); `estimate_panel_fe` fits intercept, market, B, 11 month dummies and 5 continent dummies (rank 19 asserted); a SHA-256 fingerprint and `run_id` are written to a sidecar and cross-checked against the counterpart scope's sidecar.
- **Outputs**: `Dict[str, Any]` with `coefficients`, `std_errors`, `p_values` and `diagnostics`, keyed by sector or by `global`.
- **Transformation**: the long panel becomes fixed-effects climate coefficients with dependence-robust inference.
- **Research role**: shared estimator for Equations (9) and (10), adding fixed effects "to absorb systematic variations independent of temperature extremes".

$$
R_{s,k,t} - R_{f,t} = \alpha_s + \beta_{MKT,s}(R_{MKT,t} - R_{f,t}) + \gamma_s B_{k,t} + \text{FE}_{\text{month}} + \text{FE}_{\text{continent}} + \epsilon_{s,k,t}
$$

- **Code/paper note**: the manuscript names Newey-West HAC errors; the code's headline errors are Driscoll-Kraay (month-summed scores, Bartlett lag from the number of months, $t$ on $T_{months} - 1$ degrees of freedom). Stacked-row Newey-West is kept only as a sensitivity diagnostic. This is a deliberate inferential deviation. The month effects are 12 calendar-month dummies (one dropped), as the text specifies.

### Task 30 — `run_mopso_optimization`

- **Inputs**: `r: np.ndarray` (120,), `sigma: np.ndarray` (120, 120), `alpha_fn: Callable[[np.ndarray], np.ndarray]`, `p_t: np.ndarray` (6,), `rho_matrix: np.ndarray` (6, 6), `mopso_params: Dict[str, Any]`, `seed: int`, keyword-only `third_objective_fn: Optional[Callable[[np.ndarray, np.ndarray], float]] = None`.
- **Process**: validates inputs (`validate_mopso_inputs`) and seeds one PCG64 stream; evaluates $[-\boldsymbol{w}^\top \boldsymbol{r},\ \boldsymbol{w}^\top \boldsymbol{\Sigma} \boldsymbol{w},\ \text{CEV}]$ in batch (`evaluate_population`); repairs positions with Duchi (2008) simplex projection (`enforce_simplex`); maintains repository and grid (`pareto_dominance_filter`, `deduplicate_repository`, `build_leader_grid`, `select_leader`, `prune_repository`).
- **Outputs**: `Dict[str, Any]` with the Pareto archive weights and objectives, the convergence trace and the optimiser-only `runtime_seconds`.
- **Transformation**: point-in-time inputs become a non-dominated set of long-only, fully invested portfolios.
- **Research role**: Algorithm 1 (Appendix C.2) solving (19a) to (19c); "MOPSO aims to identify the Pareto Front". Algorithm 1 as summarised from the paper:

1. Initialise $N_{pop}$ particles within $(lb, ub)$ summing to 1, velocities 0, $pbest \gets objs$; set the repository to the non-dominated particles; build the grid with $N_{grid}$ cells per objective and inflation offset $dc = (s_{\max} - s_{\min}) \cdot \alpha$.
2. For $t = 0$ to $iter - 1$, set the mutation probability $pm \gets (1 - t/(iter - 1))^{1/\mu}$.
3. For each particle $i$, choose $gbest\_pos \gets rep[\operatorname{select\_gbest}(\beta)]$ and update $vel[i] \gets \omega\, vel[i] + c_1 r_1 (gbest\_pos - pos[i]) + c_2 r_2 (pbest\_pos[i] - pos[i])$.
4. Set $pos[i] \gets pos[i] + vel[i]$, restore the bounds and the unit sum, and recompute $objs[i]$.
5. If $\operatorname{rand}() < pm$, mutate; accept $new\_pos$ if $new\_obj$ dominates $objs[i]$, or if $objs[i]$ does not dominate $new\_obj$ and $\operatorname{rand}() < 0.5$.
6. Replace the personal best under the same dominance-or-coin rule.
7. Extend the repository, remove dominated solutions, rebuild the grid, and delete via $\operatorname{select\_deletion}(\gamma)$ while the repository holds more than $N_{rep}$ members; return the repository and its objectives.

- **Code/paper note**: randomness is drawn in fixed per-generation blocks rather than per particle (JC-mopso-vectorized-draw-order), so streams differ from a literal loop while the rules do not. `mutate` is undefined in the paper; the code uses fixed Gaussian noise ($\sigma = 0.05$) plus projection. The grid is rebuilt again after pruning. The text calls $c_1$ social, matching the formula, whereas Table C.10 labels $c_1$ personal; this is immaterial at $c_1 = c_2$.

### Task 40 — `run_research_pipeline`

- **Inputs**: `stage_inputs: Mapping[int, Mapping[str, Any]]` (per-task keyword arguments), `config: Optional[Mapping[str, Any]] = None`, `out_dir: Optional[str] = None`, `stages: Optional[List[int]] = None`, `fail_fast: bool = True`, and `namespace: Optional[Mapping[str, Any]] = None`, the symbol table holding the `orchestrate_task_N` callables (None selects the running notebook's own namespace).
- **Process**: `resolve_pipeline_stages` fixes the canonical 38-stage order (Tasks 1 to 39 without 30); `validate_pipeline_inputs` checks the per-stage keyword arguments against the shared configuration; `execute_pipeline_stages` resolves each `orchestrate_task_N` lazily from the notebook namespace (`load_stage_orchestrator`) and runs it once with monotonic timing; `build_pipeline_manifest` and `persist_pipeline_manifest` record the run.
- **Outputs**: `Dict[str, Any]` with `stages` (artifacts keyed `task_N`), `manifest` and the overall `passed` flag.
- **Transformation**: one configuration and a map of stage inputs become the artifacts of the requested stages. Each stage receives only the keyword arguments supplied for it; outputs are not forwarded between stages. A run from raw data therefore calls it once per stage (`stages=[N]`) in canonical order, building each stage's inputs from the deliverables already returned (see the Usage Example).
- **Research role**: the top-level orchestrator, realising "Design of pipelines with typed inputs and outputs that decouple climate, regression, exposure, metric, optimization, and backtest components."
- **Equations**: none directly; Equations (1) to (3), (5), (6), (8) to (12), (16), (19a) to (19c) and (20) run inside the stages.
- **Code/paper note**: Task 30 contributes its MOPSO engine through reuse in Tasks 31, 33, 34, 37 and 38 rather than as a stage. With `fail_fast=False`, failures are collected in the manifest. Hardware-scaled manifest fields appear only when Task 31's anchor runtime is available.
- **Failure mode**: type-contract breaches raise `TypeError`, rejected stage resolution or inputs raise `ValueError`, a failing stage under `fail_fast=True` raises `RuntimeError` with chained context, and a stage orchestrator or Task 1 symbol missing from the namespace raises `ImportError`. `out_dir` receives both `pipeline_manifest.json` and Task 1's `library_checklist.json`; stages' own default output paths are relative to the current working directory, so callers should pass explicit output directories in each stage's kwargs.
