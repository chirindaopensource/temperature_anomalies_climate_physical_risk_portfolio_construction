# ==========================================================================#
#
#  Temperature Anomalies and Climate Physical Risk in Portfolio Construction
#
#  A dynamic, modular physical climate risk engine converting raw climate
#  observations into time-varying extreme-event probabilities and
#  cross-regional dependence structures, aggregating them into firm and
#  portfolio exposure/volatility metrics weighted by tangible-asset
#  intensity and continental revenue shares, embedded as a third objective
#  alongside expected return and market variance in a multi-objective
#  optimisation producing a Pareto frontier.
#
#  Core Methodological Components:
#  * Standardized temperature anomalies via rolling climatology and 2-sigma
#    thresholding (Eq. (1)-(2))
#  * Logistic regression of extreme-event probability with a quadratic
#    time trend (Eq. (3))
#  * Frechet-Hoeffding Bernoulli comonotone/countermonotone bounds on
#    joint exceedance probability (Eq. (5)-(6))
#  * Climate-augmented CAPM and two-way fixed-effects panel regression of
#    sector-continent returns on temperature anomalies (Eq. (8)-(10))
#  * Asset-intensity-weighted Climate Risk Exposure and Climate Exposure
#    Volatility construction (Eq. (11), (12), (16))
#  * MOPSO multi-objective particle swarm optimisation over return,
#    variance, and climate exposure objectives, with backtest (Eq. (19a)-
#    (19c))
#
#  Technical Implementation Features:
#  * Newey-West HAC-robust standard errors for panel/time-series estimates
#  * Ledoit-Wolf shrinkage estimation of the covariance matrix
#  * Duchi et al. Euclidean projection onto the probability simplex
#  * Hypervolume indicator and spacing metric for Pareto-front quality
#  * AUROC / AUPR classification-quality diagnostics for the logistic fit
#  * Reproducibility manifests (hashes, seeds, environment probes) for
#    every pipeline stage
#
#  Paper Reference:
#  Azzone, M., Bechi, C., & Sbaiz, G. (2026). Temperature Anomalies and
#  Climate Physical Risk in Portfolio Construction. arXiv preprint
#  arXiv:2604.11143. https://arxiv.org/abs/2604.11143
